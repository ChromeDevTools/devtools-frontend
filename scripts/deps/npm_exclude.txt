# rsync filter rules that scripts/deps/manage_node_deps.py applies to
# node_modules before archiving it for gs://chromium-nodejs (see
# docs/cookbook/dependencies.md). `+ pattern` keeps, `pattern` drops, and the
# first matching rule wins, so keeps come first. Any change here changes the
# archive: re-run `./dt install-deps --upload`.
#

# tests.

# with a full build, test and lint run; the reference check only knows paths
# mentioned in GN and Python files, not what Node loads at runtime.

# only loads lib/typescript.js from it, not the compiler, language server and
# typings installer binaries (25 MB).
